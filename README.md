# Premium Glassmorphism Calculator

A beautiful, fully functional web-based calculator built with pure HTML, CSS, and JavaScript. 

## Features

- **Premium Design**: Sleek dark-mode glassmorphism interface with a dynamic gradient background.
- **Micro-Animations**: Smooth hover and active states for a tactile feel.
- **Keyboard Support**: Fully navigable and usable via keyboard (numpad, enter, backspace, etc.).
- **Responsive**: Adapts gracefully to different screen sizes.
- **Core Operations**: Addition, subtraction, multiplication, division, and modulo.
- **Error Handling**: Handles edge cases like division by zero.

## Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Variables, Flexbox, Grid, Animations, and Backdrop Filter for the glassmorphism effect.
- **Vanilla JavaScript (ES6)**: Object-Oriented approach for clean, maintainable logic.

## Usage

Simply open the `index.html` file in any modern web browser to start using the calculator. No build steps or servers are required!
